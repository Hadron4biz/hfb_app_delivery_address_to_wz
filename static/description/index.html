Delivery Address To Outgoing Transfers

Change the delivery address on an order, and every open transfer follows - no manual fix-up.

The problem

A customer moves, or an order ships to a different site than usual - so you update the delivery address on the confirmed sale order. Odoo shows a warning suggesting you also update the related deliveries, but doesn't actually do it. Forget that manual step, and the goods ship to the wrong place.

How it works

1

Change the delivery address

On the sale order, as usual, and save.

2

Open transfers update themselves

Every related outgoing transfer that isn't done yet gets the new address.

3

It's logged

A chatter note on the order and each transfer records exactly what changed.

Where it applies

Confirmed sale orders with related outgoing transfers (sale.order / stock.picking). Requires the Sales and Inventory apps. No new models, no extra configuration, no security rules - install it and delivery address changes just propagate.
